命令行怎么打

pip install -r requirements.txt
python luogu_punch.py                 # 打一次
python luogu_punch.py --json          # JSON 输出
python luogu_punch.py --schedule      # 常驻, 每天 10:00 (北京时间)
scripts\install_task.ps1              # 注册成 Windows 计划任务

凭据只从环境变量读: LUOGU_CLIENT_ID 与 LUOGU_UID, 仓库里只有空的 .env.example 模板。

这个站点怎么用

站点有三种运行形态, 页面会自动检测当前是哪种。

本机代理模式

在本机跑 python server/app.py, 密钥只在服务端进程环境里, 浏览器不接触任何凭据。 填题号能自动抓洛谷题面, 打卡按钮也可用。

自带密钥模式 (BYOK)

GitHub Pages 上没有后端, 所以用你自己带的密钥直连模型接口。 密钥只存在本机浏览器 localStorage, 不经过任何服务器。 有的厂商不返回 CORS 头, 浏览器会被拦 —— 哪些厂商能直连, 下面这行写着; 想用被拦的那几家就改跑本机代理模式。

演示模式

提交一份预生成的样例讲解, 让没有密钥的人也能看到完整效果。 注意: 示例题的解析是预先生成的, 不是实时调用。
