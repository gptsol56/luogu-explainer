# 淳阳项目组 · 第一阶段前置学习任务
**前置任务不作为考核，但作为后续考核时的重要依据**

## 一、学习内容

### 1. Git 基础与版本管理

【学习目标】

了解 Git 在软件开发中的作用，掌握基本的版本控制操作，初步建立代码管理和团队协作意识。


1. Git 是什么？为什么它能够成为广泛使用的版本控制工具？
    
2. 为什么开发者需要版本控制？直接复制文件备份有什么局限？
    
3. Git、GitHub 和 Gitee 分别是什么？它们之间有什么区别？
    
4. 什么是仓库、提交、分支和合并？
    
5. 在团队协作中，如何使用 Git 管理和同步项目文件？
    

【推荐学习资源】

《Git + GitHub 核心概念大串讲，从零到一全攻略》  
[https://www.bilibili.com/video/BV1ySLc6QEcB/](https://www.bilibili.com/video/BV1ySLc6QEcB/)

Git 交互式练习：  
[https://woyeyao.github.io/Git-Interactive-Tutorial/](https://woyeyao.github.io/Git-Interactive-Tutorial/)

Learn Git Branching：  
[https://learngitbranching.js.org/?locale=zh_CN](https://learngitbranching.js.org/?locale=zh_CN)

【实践要求】

1. 安装 Git，完成基本配置。
    
2. 选择注册 GitHub 或 Gitee 账号，创建自己的第一个远程仓库。
    
3. 掌握 git init、add、commit、push、pull 等常用操作。
    
4. 尝试创建分支、切换分支并进行合并。
    
5. 使用 Git 管理本阶段的学习文件和笔记，保留清晰的提交记录。
    

建议有条件的同学优先尝试 GitHub；如果暂时无法正常访问 GitHub，可以先使用 Gitee 完成相关练习。

不要求死记硬背所有命令，但应当理解常见操作的作用，并能够独立完成基本的仓库管理。
### 2. AI Agent 基础认知与实践

【学习目标】

了解大语言模型（LLM）与 AI Agent 的区别，初步理解 Agent 的工作机制，并尝试利用 AI 辅助完成学习或开发任务。
1. 什么是 AI Agent？它与普通的大语言模型对话有什么区别？

2. 除了底层 LLM，一个 Agent 系统通常还包含哪些部分？工具调用、上下文管理、任务规划等机制分别起到什么作用？

3. 什么是 Harness？它如何组织模型、工具和执行流程？

4. 我们应该怎样描述任务、提供上下文，才能让 AI 更准确地完成工作？

5. AI Agent 能否成为我们的“外置大脑”，融入日常学习、资料整理和项目开发？

### 3. 开发环境完善与自主探索

【学习目标】

学会根据实际需求主动查找技术资源，逐步建立属于自己的开发和学习环境。


1. 了解 GitHub 开源社区，尝试搜索自己感兴趣的项目。
    
2. 学会通过官方文档、插件市场及技术社区寻找合适的开发工具。
    
3. 尝试阅读英文技术资料，了解不同工具的功能及适用场景。
    
4. 根据所选专业方向，完善常用开发软件、插件及学习工具。
    
5. 了解常见 AI 工具的使用方式及账号注册要求。
    

有兴趣的同学也可以尝试注册 Gmail谷歌账号，了解 ChatGPT、Claude 等不同 AI 工具的特点，为今后探索相关技术做好准备。此项仅作为拓展建议

【实践要求】

结合自身学习或项目需求，在 GitHub、插件市场或相关技术社区中寻找几个感兴趣的开源项目、插件或开发工具，并记录：

1. 工具或项目名称及链接。
    
2. 它主要能够解决什么问题。
    
3. 自己为什么对它感兴趣。
    
4. 未来可以如何应用到学习或项目实践中。
    

重点不在于找到多少工具，而在于培养主动检索、筛选信息和解决实际问题的能力。

### 4. 学习笔记与总结
在学习上述三个内容的时候记录下自己的学习笔记

【基本要求】

建议使用 Markdown 整理学习笔记，可以选择 Obsidian 或其他自己习惯的工具。
整理完之后可以尝试往博客网站上发布，比如csdn等，之前有一个进入大厂的老学长就是不断在博客网站上记录自己的学习经历。很有意思，也能作为展示自己的一面

笔记不要求篇幅很长，但是要沉淀自己的思想

尤其希望大家记录自己实际遇到的问题与解决过程，而不是简单复制视频字幕、教程内容或 AI 生成的总结。

笔记的意义不只是完成任务，更是为今后的学习积累可以反复查阅的资料。

1. Git 学习记录

### 附加任务:（根据自己具体情况选择，完成的好会作为后续考核的依据）
有余力的同学可以尝试结合 AI Agent，对自己的项目使用 Git 进行版本管理。

如有实际作品，可在仓库中附上运行截图、演示链接或使用说明。

## 三、注意事项

1. 本阶段重点考察学习过程、实践能力与主动探索意识，不要求大家一开始就具备很高的技术水平。
    
2. 鼓励大家积极使用 AI 工具辅助学习，但应当理解相关知识，并对生成结果进行检查和验证。
    
3. 遇到问题时，可以先尝试阅读报错、查阅文档、搜索资料或借助 AI 分析，仍无法解决时可以在群里发出来讨论
    
4. 学习笔记应尽可能体现自己的理解和思考，不需要追求篇幅，不要ai
    
5. 鼓励大家在群内交流学习经验、分享有用的工具与资料，共同解决遇到的问题。
    

## 四、写在最后

这次前置学习并不是希望大家在短时间内掌握所有工具，而是希望大家开始建立属于自己的学习方式。

Git 帮助我们管理和积累成果，AI Agent 帮助我们探索更高效的工作方式，而持续记录与总结则能够让每一次学习真正有所沉淀。

相比于最终完成了多少内容，我们更希望看到大家主动探索的过程，以及面对陌生技术时独立思考、尝试解决问题的能力。

希望大家认真对待本次学习任务，在实践中不断积累经验，为后续各方向的专业学习与项目开发打好基础。
