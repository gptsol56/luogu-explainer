## 一、任务拆解：要回答的 5 个问题

| # | 问题 | 关键词 |
|---|------|--------|
| Q1 | 什么是 AI Agent？与普通 LLM 对话的区别？ | LLM、Agent、自主性 |
| Q2 | Agent 系统除 LLM 外还包含什么？工具调用 / 上下文管理 / 任务规划的作用？ | Tool、Context、Planning |
| Q3 | 什么是 Harness？它如何组织模型、工具和执行流程？ | Harness、执行框架 |
| Q4 | 怎样描述任务、提供上下文，才能让 AI 更准确地完成工作？ | Prompt、上下文、验收标准 |

任务明确说明：**不要求掌握底层实现原理**，重点是把 5 个问题想清楚 + 动手用起来。

## 三、每日安排

### Day 1（11.20 周五）· 建立概念框架 —— 对应 Q1、Q2
- [ ] 看视频①（可 1.25–1.5 倍速，分 2 段看完，总投入约 2.5h）
- [ ] 边看边用自己的话画一张概念关系图：LLM → Token/Context Window → Prompt（User/System）→ Tool/MCP → Agent → Skill
- [ ] 写 Q1、Q2 的回答初稿（每题 3–5 句话 + 1 个自己的例子）
- [ ] **动手小实验**：让任意 AI 工具做同一件事（比如"总结我这段 Git 笔记"）两次——一次只丢一句话，一次给全上下文和明确要求，把两次结果差异记进笔记

### Day 2（11.21 周六）· Skill 与任务描述 —— 对应 Q3、Q4
- [ ] 看视频②（约 2h）
- [ ] 记录三个要点：Skill 的本质是什么、渐进式披露解决什么问题、Skill 与 MCP 怎么选
- [ ] 写 Q3、Q4 回答初稿
- [ ] **动手小实验**：亲手给 AI 写一份"合格的 任务描述"（含：目标、背景上下文、约束、期望的输出格式、验收标准），再故意写一份模糊的，对比两次结果 → 这就是 Q4 的实证材料

### Day 3（11.22 周日）· 外置大脑实践 —— 对应 Q5
- [ ] 看视频③（34 分钟，轻松看）
- [ ] **动手实践（本周核心实践）**，二选一：
  - A. 建立自己的 `USER.md` / `MEMORY.md` 雏形：把我的习惯、正在学的东西、常用约定写进去，让 AI 每次不用重复交代背景
  - B. 用 Agent 完成一次真实学习任务：如"把这周 4 天的 Git 笔记整理成复习提纲并指出我的薄弱点"，记录它做得好/不好的地方

## 四、看视频的方法（重要）

1. **问题驱动**：每个视频开看前先扫一眼它对应的问题（见第二节表格），暂停时用自己的话记一句，而不是抄字幕
2. **概念不纠结**：第一遍看不懂的概念（如 MCP、Harness）先标记，看第二遍或问 AI"用大白话解释 X，并举一个例子"
3. **每段视频看完必须配一次动手**：只看不做 = 没学。实验做错、AI 答非所问的经历恰恰是笔记里最有价值的部分
